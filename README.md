# One Pace Intro Skipper

Chrome + Firefox extension that adds a **Skip Intro** button to [One Pace](https://onepace.net/en/watch)
episodes, which are played on pixeldrain.

Intro times are built in for every episode (492 across all arcs at the time of writing), measured from the
actual files — intros differ per arc, some episodes have a scene before the intro, and some
have no intro at all.

## Repository layout

```
extension/          the browser extension (load this folder)
  manifest.json     Manifest V3, works in Chrome and Firefox
  content.js/.css   Skip Intro button + settings gear on the pixeldrain player
  popup.html/.js    toolbar popup: auto-skip toggle, saved times
  defaults.js       built-in intro timestamps (generated by tools/)
tools/              scripts that measure the timestamps
  data/             episode list, chapter markers, audio results
```

## Install

**Chrome / Edge / Brave**
1. Open `chrome://extensions`
2. Turn on **Developer mode** (top right)
3. **Load unpacked** → select the `extension` folder

**Firefox** (115+)
1. Open `about:debugging#/runtime/this-firefox`
2. **Load Temporary Add-on…** → select `extension/manifest.json`
   (temporary add-ons are removed when Firefox restarts; for a permanent install,
   zip the contents of `extension/` and sign it at addons.mozilla.org as an unlisted add-on)

## Use

- Open an episode from onepace.net. While the intro plays, a **Skip Intro ⏭** button
  appears in the bottom-right of the player. Click it or press **S**.
- Toolbar popup: turn on **Skip intros automatically**, and view/edit/delete saved times.

### Fixing a wrong timestamp

Hover the video → click the **gear** in the top-right corner:
- **Whole arc** / **This episode only** — choose what your change applies to
- **Set intro START / END to now** — marks the current playback time
- **This episode has NO intro**
- **Clear** — go back to the built-in value

Priority: your episode setting → your arc setting → built-in episode → built-in arc.

## How the timestamps are measured (`tools/`)

1. `probe_chapters.py` reads the official chapter markers ("Opening", "Episode", …) that
   newer One Pace files contain. These are exact and cost only a few KB per file.
2. `run_all.py` handles every episode without an "Opening" chapter: it downloads the first
   4 minutes of audio and finds the intro by audio fingerprinting (the theme song is the
   audio that repeats across episodes, like Plex/Jellyfin intro detection). Checked against
   the official chapters, it lands within ~1 s.
3. `merge.py` (run automatically by `run_all.py`) writes `extension/defaults.js` —
   chapters first, audio otherwise.

A few episodes whose opening is unique (no other episode to compare against) were checked
frame by frame and stored in `tools/data/manual.json`; `merge.py` always applies them.

Requires Python 3 and ffmpeg on PATH. `tools/data/files.json` is the episode list
(pixeldrain 480p albums); refresh it when One Pace releases new episodes.

```
cd tools
python probe_chapters.py
python run_all.py
```

pixeldrain answers **403 Forbidden** when hit too hard; the scripts go slowly and back
off, but if it happens just wait a while and run them again (they resume).

The audio cache goes to `%TEMP%\onepace-intro-cache` (safe to delete afterwards).
